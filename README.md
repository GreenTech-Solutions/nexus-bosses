# Nexus Bosses

Nine summonable bosses in three circles on Nexus, the planet of
[Nexus Extended Promethium Endgame](https://mods.factorio.com/mod/Nexus-Updated), for Factorio 2.1. Craft a summon
beacon, light it on Nexus, defend it through the countdown and defeat the boss that comes. Beating a circle opens the
next one; beating all three opens the warp drive.

Mod portal: [Nexus Bosses](https://mods.factorio.com/mod/nexus-bosses). Bug reports: the issues of this repository.

Requires Nexus-Updated (with Nexus-Threat-Updated and Nexus-Graphics-Updated), Big Monsters, Toxic Biters, Arachnids
enemy and Electric flying enemies; razi-protocol is optional.

Remote interface `nexus-bosses`: `get_state()`, `set_ignore_player_presence(bool)` (for headless tests),
`abort_summon(destroy_bosses)`. Console command `/nexus-bosses-abort` (administrators) stops a stuck trial.
